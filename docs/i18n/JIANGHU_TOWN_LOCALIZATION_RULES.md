# 《江湖小镇之凰龙府》V0.1 英文本地化规则

适用范围：仅 OPC 比赛用 V0.1 双语副本的 Round 1；简体中文是权威源文。

## 三层工作法

### UI：标准翻译

开始、保存、读取、设置、返回、音量、历史、帮助等使用准确、自然、简洁的标准英语。优先保证可扫读性、按钮长度和 Ren'Py 常用语境。

### Canonical / Semantic：正典与语义体系

Canonical 指**正典设定 / 权威设定**；Semantic 指**语义体系 / 世界观概念体系**。国家、地名、人物、势力、门派、称号、丹药、货币、事件等必须采用术语表的批准译名。同一 key 的译名不可随对白任意变动。

稳定 ID 或术语 key 只是语义体系中的一个节点，并不等于完整 ontology（世界观概念体系）。本项目不把整句对白 code 化，也不把人物语言拆为机械模板。

### Narrative：叙事表达

Narrative 指**叙事表达**。英文采用文学级本地化：保留事实、人物关系、信息功能、情绪、笑点、武侠身份与中国文化语境；可重组句式以使英语自然。不得新增剧情、关系、承诺、现代网络梗，或把中国文化替换成西方文化。

## 操作规则

- V0.1 可运行源码决定本轮实际可译内容；世界观文档只指导已存在内容的术语、身份和语气。
- 已确认的正典拼写应修正可运行源码：开庵镇、雷云峰；图片内文字保持原样。
- 图片内嵌中文不翻译、不重绘；社媒图不在游戏国际化范围。
- 未来 zh-Hant-TW 和 Vietnamese 必须直接从简体中文源文翻译，不以英语为中间源。
