江湖小镇之凰龙府

Jianghu Town: Huanglong Fu

一镇一江湖。

《江湖小镇之凰龙府》是沐茂科技正在创作的原创叙事游戏，从真实地域、地方历史与想象江湖中生长。

有些地方终会改变，故事让它们留下。

关于创作者

沐茂科技（Mumao Tech）是一家位于中国海南的独立数字科技公司，围绕人的故事、记忆、连接与想象创造数字产品。

Jianghu Town: Huanglong Fu is an original narrative game in development by Mumao Tech, born from real places, local history and an imagined jianghu.
