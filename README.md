# Jianghu Town: Huanglongfu

**Jianghu Town: Huanglongfu** is an early Ren'Py narrative game prototype created by Mingren Wang (Gabriel Wong).

The story is set in the fictional town of Kai'an, located in Huanglongfu. It explores a warm, everyday jianghu world through character-driven storytelling, local relationships, and small-town mysteries.

This repository contains an early MVP V0.1 prototype prepared for public portfolio and open-source reference.
